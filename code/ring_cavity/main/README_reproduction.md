# 环形腔光谱复现实验

`reproduce_ring_spectrum.m` 用现有 GMMNLSE 引擎计算环形腔的逐圈演化，保存不同取样端口和输出尾纤长度下的复电场及光谱。`plot_ring_reproduction.m` 从保存的场计算原始能量谱密度并绘图。用户同意同时保留原始曲线和平滑展示，因此另提供 `export_ring_spectrum_display.m`；它不改变传播结果，输出文件和图内均明确标注平滑。

## 一键生成候选图

在 MATLAB 中打开本文件所在目录，运行 `run_ring_spectrum_figure`。该入口按表中光纤参数、90%宽带输出、阶4超高斯滤波器计算40圈，再输出原始谱和2/8 nm半高全宽的高斯平滑展示。滤波器阶数和宽带输出接法是明确的补充假设，不是表或结构图唯一规定的结论。40圈结束也不保证达到稳态；程序会在未收敛时警告。普通高斯滤波器也做了对照，但不作为此入口的最终候选。

## 参数与模型

腔内传播顺序为：4.0 m 增益光纤 → 0.4 m 无源光纤 → SF1 → 1.5 m 无源光纤 → SF2 → 3.2 m 无源光纤 → 回到增益光纤。共同设置包括：计算中心波长 1035 nm、增益光纤 MFD 11.1 μm、纤芯/包层直径 10/125 μm、NA 0.08、976 nm 同向泵浦 4 W，以及 SF1 1040/5 nm、SF2 1030/3 nm。代码在 SF1 位置区分以下四种实现：

| `case_name` | 光纤与滤波器参数处理 | 输出接法 |
| --- | --- | --- |
| `legacy_rejected` | 保留历史代码的关键计算约定 | 取 SF1 的历史拒绝端，场振幅系数为 `1-T` |
| `table_rejected` | 按表中 MFD、吸收和带宽重新计算相关量 | 取 SF1 的理想互补端，场振幅系数为 `sqrt(1-T^2)` |
| `table_broadband90` | 同 `table_rejected` | 在 SF1 前加入宽带 90/10 耦合器：90% 能量输出，10% 再通过 SF1 留在腔内 |
| `legacy_broadband90` | 同 `legacy_rejected` 的光纤与滤波器约定 | 同上述宽带 90/10 接法，用于单独比较输出接法的影响 |

其中 `T` 是实数滤波器场透射系数。`legacy_broadband90` 是组合比较项，不表示原项目采用过这种接法。宽带耦合模型中，SF1 拒绝的剩余光不计入所定义的宽带输出。

表中只有“Output coupling = 0.9”，结构图只将 OUTPUT 连在 SF1 处，不能由此唯一确定输出是滤波器拒绝端，还是 SF1 附近的独立宽带耦合端。拒绝端的输出比例随入射光谱变化，通常不等于固定 90%；因此这里将两种解释分别计算。宽带模型的 `sqrt(0.9)` 是耦合器对实际传播场的作用，同时改变腔内反馈，不是绘图时将曲线乘以常数。

历史约定与表值之间有以下差异：

- 历史无源光纤先按引擎默认 MFD 5.95 μm 计算有效面积及非线性重叠量 `SR`，随后才把 `MFD` 字段改为 10.5 μm；这个赋值不会重新计算 `SR`。`legacy_*` 保留该行为；`table_*` 在初始化时传入 10.5 μm，使有效面积与 MFD 一致。
- 历史代码调用增益初始化后，将掺杂浓度强制设为 `N_total = 9e7` ions/μm³，替代由吸收数据推算的浓度。`legacy_*` 保留该覆盖；`table_*` 使用 975 nm、6.4 dB/m 吸收数据及所选截面文件推算浓度，并按增益 MFD 11.1 μm 计算信号与纤芯的重叠。
- 两组滤波器均采用八次幂的超高斯函数，但历史公式把 `sqrt(log(2))` 放在八次幂内，传入的带宽不等于实际强度半高全宽。`table_*` 使用 `T = exp(-0.5*log(2)*x^8)`，使带宽参数对应频域中的强度半高全宽；频域带宽由给定波长带宽换算。
- 历史拒绝端使用 `1-T`；理想无损互补端使用 `sqrt(1-T^2)`。两者的光谱和能量分配不同，不宜混用。

参数表还没有给出实际光纤的各阶色散、非线性折射率、滤波器阶数和相位响应、准确的输出接法及器件损耗。当前实现沿用引擎的单模光纤色散和非线性默认值、Liekki Yb 截面文件，并假设无额外滤波器相位。因此，`table_*` 表示将已列出的表值落实到模型，并不表示所有物理参数都由该表唯一确定。

输出尾纤是腔外的额外假设，参数表和结构图均未明确包含它。原项目代码曾在输出后加入 0.2 m 无源光纤；本入口默认比较 `[0, 0.05, 0.1, 0.2, 0.4, 0.6]` m，分别从同一个最终输出场开始传播，不让尾纤结果反馈进腔内。0 m 对应刚取出的输出。

## 运行

在 MATLAB 中进入项目根目录后执行：

```matlab
addpath(fullfile(pwd, 'code'));
setup_mamyshev_project();

r = reproduce_ring_spectrum('legacy_rejected');
```

将模型名替换为上表中的其他值即可分别运行。入口默认使用 CPU、关闭传播进度窗口，时间窗口 50 ps、`Nt = 2^14`，最多 100 圈。可传入第二个结构体参数覆盖数值设置，例如：

```matlab
options = struct('Nt', 2^15, 'max_rt', 200, ...
    'tail_lengths_m', [0 0.2], 'tag', '_N32768');
r = reproduce_ring_spectrum('table_rejected', options);
```

`tag` 会附加到输出目录名；重复使用同一个模型名和 `tag` 会更新该目录中的同名文件。可配置项以入口函数的 `cfg` 结构体为准，未知字段会报错。增大圈数和采样点数用于数值检查，不能保证脉冲一定收敛。

默认收敛判据是在至少 20 圈后，输出能量与完整输出光谱的相对变化均小于 `1e-3`，且连续满足 5 圈。`result.status` 区分 `converged`、`maximum_roundtrips`、`pulse_died` 和 `nonfinite_field`；达到最大圈数不等于达到稳态。

也可从同一采样网格的检查点继续计算：

```matlab
options = struct('initial_file', '/完整路径/checkpoint.mat', ...
    'Nt', 2^14, 'time_window_ps', 50, 'max_rt', 100, 'tag', '_continued');
r = reproduce_ring_spectrum('legacy_rejected', options);
```

这会取检查点的腔内返回场作为新的初始场，圈数与收敛历史重新计数。`Nt` 和时间窗口必须与检查点一致；同一物理模型的续跑应保持模型名一致。

## 输出与原始数据

额外选项：`filter_order=1` 为普通高斯，默认4为八次幂超高斯；二者保留相同标称中心与强度FWHM（仅 `table_*` 分支保证这一点）。`spontaneous_raman=false` 仅供确定性诊断，关闭随机自发项但仍保留受激Raman；不能把此设置与默认随机模型混称。历史对照第一次运行还按975nm/6.4dB/m填写了增益初始化字段，但随后覆盖为9e7，实际浓度不受该字段影响；当前入口已恢复历史920nm/1.7dB/m字段并保留同样浓度覆盖。

所有输出位于项目根目录下的 `results/ring_cavity/generated/<case_name><tag>/`，该目录已由 `.gitignore` 排除。

| 文件 | 内容 |
| --- | --- |
| `checkpoint.mat` | 每 5 圈及结束时保存的检查点，包含模型设置、逐圈历史、各端口复电场和腔内返回场 |
| `result.mat` | 本次循环结束后再计算输出尾纤所得的结果，包括各尾纤长度下的复电场 |
| `raw_spectra.csv` | SF1 前、SF1 透射端、SF1 拒绝端及各尾纤输出的原始能量谱密度 |
| `metrics.csv` | 时域能量、光谱积分、谱峰、10%谱边界、1040 nm 缺口比和时间窗口边缘能量占比 |
| `convergence.csv` | 无表头；依次为圈数、输出能量 nJ、腔内返回能量 nJ、能量相对变化、光谱相对变化 |
| `diagnostics.png` | 端口光谱、尾纤比较、能量演化和收敛诊断 |
| `spectrum_tail_XXXmm.png` | 指定尾纤长度的单独输出光谱，例如 `spectrum_tail_200mm.png` |

原始绘图直接使用复电场的离散傅里叶谱。频域能量谱密度按 `(N*dt)^2/1000` 换算为 nJ/THz，再乘以 `c/lambda^2` 换算为 nJ/nm；采用引擎的 `ifft` 频率方向约定。上述 `spectrum_tail_*` 和 `diagnostics.png` 没有高斯平滑、包络拟合、删峰、归一化到目标峰值或任意纵轴缩放。比较时应同时检查时域能量和光谱积分是否一致，以及时间窗口边缘能量是否足够小。

另运行 `export_ring_spectrum_display('/完整路径/result.mat',8,0)` 可生成8 nm高斯半高全宽的平滑展示。处理顺序是：按波长均匀网格线性插值原始谱，再与单位积分的高斯核卷积，不平移波长、不缩放幅度、不拼接目标曲线。`display_tail_000mm_fwhm_8nm.png` 同时展示原始和平滑；`*_smooth_only.png` 是标有平滑说明的单图；同名CSV和MAT保留处理后的数组与设置。8 nm是用户许可的显示处理宽度，不代表已知光谱仪分辨率，也不是物理模型中的5/3 nm滤波器带宽。
